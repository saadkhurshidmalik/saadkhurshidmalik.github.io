Project Overview

Ajzal Benaa delivers a sleek mobile commerce experience tailored for the Middle Eastern market. Built from the ground up using Flutter, the app combines cross-platform speed with native UI performance, incorporating custom internationalization engines for full Left-to-Right and Right-to-Left (RTL) layout switching.

Core Features

  • Full Localization (EN / AR): Instant language switching with complete UI layout adaptations for Arabic (RTL).
  • Dynamic Catalog: Fast product search, multi-level category filtering, and high-res image galleries.
  • Streamlined Checkout Flow: Intuitive multi-step checkout with address selection and payment gateway integrations.
  • Account & Order Tracking: Real-time order updates, address books, and order history management.

Tech Stack
