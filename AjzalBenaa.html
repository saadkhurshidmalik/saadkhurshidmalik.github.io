About the Project

Ajzal Benaa is a full-featured cross-platform E-Commerce mobile application built for seamless retail browsing and shopping. Built using Flutter, the app provides native performance on both Android and iOS devices, featuring full localization in English and Arabic (including complete Right-to-Left / RTL layout support).

Key Features

  • Bilingual Support: Full dynamic localization switching between English and Arabic with complete RTL screen adapters.
  • Product Catalog & Filtering: Smooth multi-level category navigation and real-time product search.
  • Interactive Shopping Cart: Real-time price calculation, item adjustments, and persistent cart management.
  • Multi-Step Checkout: Streamlined order placement workflow including shipping destination selection and payment processing.
  • User Profiles & Order Tracking: Seamless account setup, order history tracking, and profile management.

Tech Stack
